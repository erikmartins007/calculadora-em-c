
# Calculadora em Linguagem C

## Sobre o projeto

Este projeto consiste em uma calculadora simples desenvolvida em Linguagem C durante o semestre letivo, como atividade acadêmica da disciplina de Programação.

## Funcionalidades

- Adição de dois números
- Subtração de dois números
- Multiplicação de dois números
- Divisão de dois números
- Verificação de divisão por zero
- Mensagem para operações inválidas

## Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão stdio.h

## Como executar

1. Baixe o arquivo `calculadora.c`.
2. Abra o arquivo em um ambiente que compile Linguagem C.
3. Compile e execute o programa.
4. Informe os dois números solicitados.
5. Escolha a operação (+, -, * ou /).
6. Confira o resultado apresentado.

## Exemplo de execução

Digite o primeiro numero: 10

Digite o segundo numero: 5

Digite a operacao (+, -, * ou /): +

Resultado: 15.00
